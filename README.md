# 🏗️ .NET Project Journey

I will learn different types of .NET projects and understand **when and why each one is used.**

## 01 — Solution

A solution is a container that can hold multiple projects.

```text
MySolution
│
├── MyConsoleApp
├── MyLibrary
├── MyWebAPI
└── MyMVCApp
```

---

## 02 — Class Library

Used to create reusable code that can be shared between applications.

```text
MyLibrary
│
├── Services
├── Models
└── Helpers
```

Example:

```csharp
public class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }
}
```

---

## 03 — Console Application

Used for learning C#, creating utilities, testing logic, and practicing programming concepts.

```text
ConsoleApp
│
├── Program.cs
└── Services/
```

---

## 04 — Minimal API

Used to build lightweight HTTP APIs with minimal setup.

```text
MinimalAPI
│
├── Program.cs
├── Models/
└── Services/
```

Example:

```csharp
app.MapGet("/api/books", () =>
{
    return Results.Ok("Books");
});
```

---

## 05 — Web API

Used to build REST APIs for applications such as web, mobile, and frontend clients.

```text
WebAPI
│
├── Controllers/
├── Models/
├── Services/
└── Program.cs
```

---

## 06 — MVC Application

Used to build web applications using:

```text
Model
View
Controller
```

Structure:

```text
MVCApplication
│
├── Controllers/
├── Models/
├── Views/
└── Program.cs
```

---

## 07 — Real-World Application

After learning the individual concepts, I will combine them to build complete applications.

Example:

```text
RealWorldApplication
│
├── Frontend / MVC
├── Web API
├── Business Logic
├── Class Library
├── Database
└── Authentication
```
